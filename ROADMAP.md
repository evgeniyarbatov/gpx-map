# Roadmap

Renders GPX track segments on a map (OSM + Esri) as stills/video, for studying route detail on long or unfamiliar tracks.

## Shipped

One-command GPX-to-video pipeline (`make video`), local map server (`make run`), overridable `DATA_DIR`, `make run` target + CLAUDE.md.
