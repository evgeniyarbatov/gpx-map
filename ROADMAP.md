# Roadmap

## Why keep going

Long, unfamiliar tracks are hard to understand from a bird's-eye view — this makes route detail actually legible, which matters most exactly when it matters most: studying an unfamiliar course before you run it, not after.

## What it opens up

Once the video-generation pipeline is tested and trusted, the natural use shifts from "review a run I already did" to "study a course I haven't run yet" — pre-race reconnaissance for exactly the kind of long, unfamiliar routes ([private], `[private]`, `[private]`) where knowing the terrain in advance changes pacing decisions.

## Capability this builds

Turning an abstract GPX line into something you can actually study visually before committing to it — a rehearsal tool, not just a record-keeping one.
